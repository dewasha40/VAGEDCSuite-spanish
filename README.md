# VAG EDC15P Suite

VAG EDC15P Suite es un conjunto de programas para editar los parámetros (mapas) de las unidades de control del motor.

- **T5Suite**, para Trionic 5; **T7Suite**, para Trionic 7; y **T8Suite**, para Trionic 8.
- **Motronic Suite**, para Volvo Motronic M4.3, M4.4 y ME7.
- **VAGEDC15P Suite**, para centralitas EDC15P de VW, Audi, Seat y Skoda (PDxxx).

Si estás empezando, lee primero los manuales incluidos.

## VAG EDC15P Suite 1.3.5

VAGEDC15P Suite es una aplicación .NET para modificar el firmware de las centralitas EDC15P de VW, Audi, Skoda y Seat. EDC15P es una plataforma de Bosch utilizada en motores VAG con inyector-bomba (PDxxx). Para cambiar sus ajustes, conocidos como mapas, se necesitan herramientas específicas. EDC15P Suite permite modificar los mapas principales del sistema de gestión del motor.

El programa es gratuito y su código fuente se distribuye con la aplicación. Se agradecen los comentarios y las sugerencias para mejorarlo.

## Compilación

Para trabajar con el código fuente necesitas tener instalada una versión de VAGEDC15Suite y un entorno como Visual Studio. Configura las rutas de las dependencias necesarias (por ejemplo, las DLL de DevExpress y OfficeInterface) para que apunten a la instalación, en `../VAGEDC15Suite/`.
